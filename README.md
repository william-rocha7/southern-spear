# ⚓ Operação Southern Spear - Geospatial Intelligence

Simulação de inteligência geoespacial tática utilizando Python e Kepler.gl. O projeto visualiza vetores de ataque naval e aéreo, sistemas de defesa e movimentação de frotas em um cenário hipotético no Caribe.

## 🎯 Objetivo do Projeto
Demonstrar capacidades de **Análise de Dados Espaciais** e **Visualização de Inteligência Militar** aplicadas a cenários complexos, utilizando ferramentas open-source.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Bibliotecas:** Pandas, Kepler.gl
* **Ambiente:** Jupyter Notebook / VS Code
* **Dados:** Coordenadas geoespaciais e vetores de trajetória simulados.

## 📊 Visualização
O mapa interativo permite:
* Filtragem temporal (Timeline de combate).
* Distinção visual entre frotas (Naval, Aéreo, Defesa Costeira).
* Análise de alcance de vetores (Mísseis Tomahawk e HARM).

## 🚀 Como Executar
1.  Clone o repositório.
2.  Instale as dependências: `pip install pandas keplergl`
3.  Execute o notebook `mapa_southern_spear.ipynb`.
4.  O arquivo HTML interativo será gerado na pasta raiz.
